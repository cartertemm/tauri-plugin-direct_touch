## Default Permission

Allows all direct touch commands

#### This default permission set includes the following:

- `allow-is-supported`
- `allow-set-webview-direct-touch`
- `allow-set-region`
- `allow-remove-region`
- `allow-is-voice-over-running`
- `allow-register-listener`
- `allow-remove-listener`
